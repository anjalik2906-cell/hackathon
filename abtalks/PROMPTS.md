# PROMPTS.md — AI Usage Log

This project was built with Claude (Anthropic) as the primary AI pair-programmer,
inside a single conversation. Log below reflects the actual build sequence.

## 1. Brief intake
Prompt: full ABTalks hackathon brief pasted in — three-screen redesign
(`/`, `/dashboard`, `/day/12`), mobile-first at 390px, mocked data, no auth.

Claude's actions:
- Read the internal frontend-design guidance before writing any code.
- Chose a design direction *derived from the brief's own content*
  (GitHub commits + LinkedIn posts + late-night student usage) rather
  than a generic dashboard template — dark indigo-navy palette, a
  GitHub-contribution-graph-styled "Proof Grid" as the signature element
  reused across all three screens, Space Grotesk / Inter / JetBrains Mono
  type system.

## 2. Project scaffolding
Prompt (implicit, from brief): "any framework your AI workflow is most
productive with."

Claude's actions:
- Scaffolded a Vite + React + React Router + Tailwind project
  (`package.json`, `vite.config.js`, `tailwind.config.js`,
  `postcss.config.js`, `index.html`).
- Defined design tokens (colors, fonts, radii, shadows) directly in
  `tailwind.config.js` and `src/index.css`, including
  `prefers-reduced-motion` handling and visible focus states per the
  design guidance's quality floor.

## 3. Mock data covering edge cases
Claude's actions:
- Authored `src/data/mock.json` by hand to deliberately encode the
  edge cases named in the brief: a missed day (Day 8), an in-progress
  streak (Day 12, streak of 4), badges (earned/unearned), and a
  `dayDetail` object for Day 12 with a full task brief, requirements,
  stretch goal, and resources.

## 4. Signature component — ProofGrid
Claude's actions:
- Built `src/components/ProofGrid.jsx`, a reusable 60-cell heatmap
  component with per-cell states (done / partial / missed / today /
  upcoming) and a `compact` mode for the Day page's mini-grid, so the
  same visual language appears on all three screens instead of three
  unrelated progress indicators.

## 5. Three screens
Claude's actions:
- `src/pages/Landing.jsx` — hero with live streak stat + seeded preview
  Proof Grid, trust strip, "how it works," why-two-proofs section, track
  list, FAQ, final CTA. Copy written from scratch for this brief (no
  placeholder lorem ipsum).
- `src/pages/Dashboard.jsx` — streak card (with Streak Freeze — a
  self-initiated design addition, not directly requested, addressing the
  brief's "thoughtful idea" requirement), today's task card, progress +
  Proof Grid, standing/rank, badges grid, plus a demo-state switcher
  (`active` / `fresh` / `empty`) so every required edge case is directly
  reviewable without a login system.
- `src/pages/ChallengeDay.jsx` — task brief, numbered requirements,
  stretch goal, resources, and a proof submission form with live URL
  validation for GitHub/LinkedIn links, a submitted-state confirmation,
  and a fallback state for day IDs with no authored detail (e.g. a
  locked future day).

## 6. Verification
Claude's actions:
- Ran `npm install` and `npm run build` inside the sandboxed environment
  to confirm the project compiles with zero errors before handing it off.
- (No headless browser was available in the build sandbox to capture
  automated screenshots — visual QA of the built `dist/` output should be
  done post-deploy against the 390px viewport specified in the brief.)

## Notes
- No copyrighted third-party copy, images, or code were reproduced.
- All UI copy (headlines, FAQ answers, task brief, requirements) was
  generated by Claude specifically for this brief, not templated from a
  prior project.
